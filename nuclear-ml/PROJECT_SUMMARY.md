## 执行摘要

本项目成功验证了**物理先验在小样本机器学习中的关键作用**。基于AME2020实验数据（243个轻核），我们系统比较了三种方法：

- ❌ **直接回归**：纯数据驱动，完全失败（RMSE 33.25 MeV，比基线差247%）
- ✅ **残差学习**：SEMF+神经网络，**最佳性能**（RMSE 3.14 MeV，改进67.2%）
- ❌ **哈密顿量预测**：SO(3)等变网络，架构问题导致失败

**核心结论：** 在数据有限的科学问题中，物理知识不是可选项，而是必需品。

## 最终成果

### 定量结果

| 方法 | RMSE (MeV) | MAE (MeV) | 最大误差 (MeV) | 参数量 | 训练时间 |
|------|------------|-----------|----------------|--------|----------|
| SEMF基线 | 9.57 | 5.70 | 37.92 | 4 | — |

| **残差学习** | **3.14** | **1.77** | **16.79** | **27K** | **49.5s** |

### 定性发现

1. **物理先验的层次效应**
   - 无先验（直接回归）→ 完全失败
   - 中等先验（残差学习）→ 最佳性能
   - 强先验（哈密顿量）→ 实现困难

2. **参数效率悖论**
   - 更多参数 ≠ 更好性能
   - 27K参数 > 121K参数
   - 物理先验 = 强归纳偏置

3. **问题简化的威力**
   - 原问题：B ∈ [0, 400] MeV
   - 残差问题：ΔB ∈ [-30, +30] MeV
   - 动态范围缩小6.7倍

## 关键经验教训

### ✅ 成功经验

#### 1. 物理先验是小样本学习的关键

**背景：** 243个训练样本 vs 数千个未知核素

**发现：** SEMF虽然误差大（9.57 MeV），但提供了正确的标度和趋势

**应用：** 神经网络只需学习SEMF的系统偏差（壳效应、形变等），而非从头学习核力

**启示：** 在数据稀缺的科学领域，成熟的物理模型是不可替代的先验知识

#### 2. 残差学习降低学习难度

**原理：**
```
直接学习：NN(Z,N) → B(Z,N)  [0-400 MeV]
残差学习：NN(Z,N) → ΔB(Z,N) [-30 to +30 MeV]
最终预测：B_pred = B_SEMF + ΔB
```

**优势：**
- 动态范围缩小6.7倍
- 函数更平滑（梯度范数降低7.3倍）
- 更容易泛化到未见数据

**证据：** 测试集RMSE从9.57降至3.14 MeV（67.2%改进）

#### 3. 系统对比揭示本质

**方法：** 对比三种不同物理先验强度的方法

**结果：**
- 无先验 → 失败（-247%）
- 中等先验 → 成功（+67.2%）
- 强先验 → 实现困难

**结论：** 物理先验的"甜蜜点"在于提供足够的归纳偏置，同时保留模型灵活性

#### 4. 简单方法优先（奥卡姆剃刀）

**尝试：** SO(3)等变哈密顿量网络（理论优雅）

**结果：** 实现复杂，训练不稳定，未能收敛

**对比：** 简单的残差学习（27K参数，49.5秒训练）效果最好

**教训：** 不要过度工程化。从简单方法开始，逐步增加复杂度。

---

### ❌ 失败教训

#### 1. 直接回归在小样本下完全失效

**配置：**
- 模型：121K参数
- 数据：162训练样本
- 参数/数据比：748:1

**结果：** RMSE 33.25 MeV（比SEMF基线差3.5倍）

**原因：**
- 参数过剩导致记忆噪声而非学习规律
- 缺乏归纳偏置，无法泛化
- 优化困难（局部最优）

**教训：** 在小样本场景下，必须引入先验知识。纯数据驱动不可行。

#### 2. 哈密顿量方法的三重困境

**问题1：维度灾难**
- 哈密顿量矩阵：N×N = 400自由度（N=20）
- 训练数据：243个核素
- 信息不足以确定所有矩阵元

**问题2：梯度消失**
- 损失函数：L = (λ_min - E_target)²
- 梯度：∂L/∂H = 2(λ_min - E_target) · v_min v_min^T
- v_min分量小且分散 → 梯度消失

**问题3：架构不匹配**
- SO(3)等变网络输出球谐函数系数
- 需要复杂后处理构造Hermitian矩阵
- 维度不匹配，数值不稳定

**教训：** 物理优雅性必须与计算可行性平衡。理论完美 ≠ 实践可行。

#### 3. 数据质量 > 数据量

**初期：** 使用SEMF生成的伪数据（可以生成任意多）

**问题：** SEMF本身有系统偏差，生成的数据继承了这些偏差

**转向：** 使用AME2020真实实验数据（仅243个）

**结果：** 真实数据虽少，但质量高，训练效果显著提升

**教训：** 高质量小数据 > 低质量大数据。数据质量是第一位的。

#### 4. 过早优化的陷阱

**初期设计：** 复杂的等变网络架构，考虑所有物理对称性

**问题：**
- 实现复杂，调试困难
- 训练不稳定，超参数敏感
- 未能产生有效结果

**转向：** 简单的MLP + 物理特征

**结果：** 快速实现，稳定训练，效果最好

**教训：** 先建立简单基线，再逐步增加复杂度。不要过早优化。

## 技术细节

### 数据集

**来源：** AME2020（Atomic Mass Evaluation 2020）

**范围：** Z=2-20, N=2-28（轻核到中等质量核）

**样本数：**
- 训练集：162个核素（66.7%）
- 验证集：28个核素（11.5%）
- 测试集：53个核素（21.8%）

**划分方式：** 按质子数Z分层抽样，确保各元素均衡分布

### 模型架构

#### SEMF基线
```python
B_SEMF = a_v*A - a_s*A^(2/3) - a_c*Z²/A^(1/3) - a_a*(N-Z)²/A + δ(Z,N)
```
参数：a_v=15.68, a_s=17.23, a_c=0.714, a_a=23.45 MeV

#### 残差学习模型（最佳）
```python
# 输入特征（17维）
features = [Z, N, A, A^(2/3), Z²/A^(1/3), (N-Z)²/A, 
            pairing, magic_distance, ...]

# 网络架构
input(17) → Linear(128) → SiLU → LayerNorm → Dropout(0.1)
         → Linear(128) → SiLU → LayerNorm → Dropout(0.1)
         → Linear(64)  → SiLU → LayerNorm → Dropout(0.1)
         → Linear(1)   # 输出残差修正

# 最终预测
B_pred = B_SEMF + NN_output
```

参数量：27,905

#### 直接回归模型（失败）
```python
# 相同的输入特征（17维）
input(17) → Linear(256) → ReLU → Dropout(0.2)
         → Linear(256) → ReLU → Dropout(0.2)
         → Linear(128) → ReLU → Dropout(0.2)
         → Linear(128) → ReLU → Dropout(0.2)
         → Linear(1)   # 直接输出结合能
```

参数量：121,729

### 训练配置

**优化器：** Adam
- 学习率：1e-3
- Weight decay：1e-5（残差），1e-4（直接）

**学习率调度：** Cosine annealing
- T_max：500 epochs
- η_min：1e-6

**批大小：** 32

**训练轮数：** 500 epochs

**早停：** 验证损失20个epoch无改进

**损失函数：** MSE（均方误差）

### 评估指标

- **RMSE**（均方根误差）：主要指标
- **MAE**（平均绝对误差）：鲁棒性指标
- **最大误差**：最坏情况
- **相对误差**：百分比误差
